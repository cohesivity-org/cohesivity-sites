# cohesivity-sites

A skill for coding agents. Lets your agent build and deploy web apps with temporary hosting, databases, and file storage — no account creation, no API keys, no setup.

Works with Claude Code, Codex, Cursor, Agentty, and other agents that support skill files.

## Install

Add `SKILL.md` to your agent's skill directory, or install via your agent's skill command:

```
agentty skill add https://github.com/cohesivity-org/cohesivity-sites
```

Apps run on ephemeral tenants that last 72 hours. Users can claim a tenant to make it permanent.
